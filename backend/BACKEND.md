# Backend WB Analytics — как запустить

Backend делает твой ноутбук **временным сервером** для расширения. Расширение
отправляет спарсенные товары на `http://127.0.0.1:4000`, backend сохраняет их
в SQLite и считает метрики (скорость продаж, выручка, история цен).

## Требования

- **Node.js 22.5.0 или новее** (нужен встроенный модуль `node:sqlite`).
  Проверить версию: `node -v`. Скачать: https://nodejs.org
- **Устанавливать ничего не нужно** — внешних зависимостей нет (`npm install` НЕ требуется).

## Запуск (самый простой способ)

Дважды кликни по файлу:

```
backend\start-server.bat
```

Откроется чёрное окно с надписью:

```
[WB Analytics] backend слушает http://127.0.0.1:4000
```

**Это окно — твой сервер. Не закрывай его**, пока пользуешься расширением.
Чтобы остановить — закрой окно или нажми `Ctrl+C`.

## Альтернативный запуск (вручную)

Открой терминал (PowerShell/CMD) в папке `backend` и выпол:

```bat
node server.js
```

или

```bat
npm start
```

## Проверка, что сервер работает

Открой в браузере:

```
http://127.0.0.1:4000/api/health
```

Должен вернуться JSON: `{"ok":true,"service":"wb-analytics"}`.

## Автотест (опционально)

Проверить расчёт метрик без обращения к Wildberries:

```bat
node e2e_test.js
```

Ожидаемый результат — все проверки `✓` и `Результат: N прошло, 0 упало`.

## Настройки через переменные окружения

| Переменная   | По умолчанию            | Назначение                    |
|--------------|-------------------------|-------------------------------|
| `PORT`       | `4000`                  | Порт сервера                  |
| `WB_DB_PATH` | `backend/wb.sqlite`     | Путь к файлу базы SQLite      |

Пример: `set WB_DB_PATH=D:\data\wb.sqlite && node server.js`

## Доступ с других устройств (по желанию)

По умолчанию сервер слушает `127.0.0.1` (только этот компьютер). Если нужно,
чтобы расширение работало с другого устройства в той же Wi-Fi сети, запусти
с адресом `0.0.0.0` — для этого в конце `server.js` замени `server.listen` на
версию с host `0.0.0.0`. Учти: в открытую сеть без пароля лучше не светить.

## Где хранятся данные

База SQLite создаётся рядом с `server.js` (`wb.sqlite`). Чтобы начать
«с чистого листа» — останови сервер и удали файлы `wb.sqlite`, `wb.sqlite-wal`,
`wb.sqlite-shm`.
